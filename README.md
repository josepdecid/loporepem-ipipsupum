# Jerigonza Ipsum Generator

Minimal static app that generates lorem ipsum-style placeholder text transformed into Spanish jerigonza.

## Rules implemented

- After each vowel, add `p` and repeat the vowel.
- Example: `Hola` → `Hopolapa`

## Run locally

Open `index.html` in a browser.

If you prefer a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
